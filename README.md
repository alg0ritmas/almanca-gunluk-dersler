# Almanca Günlük Dersler

Interaktif, mobil uyumlu Almanca öğrenme paneli.

## İçerik

- Günlük ders arşivi ve geçmiş derslere dönüş
- Hikâye, Türkçe açıklama, artikel ve gramer bilgi kutuları
- Cevap kontrolü içeren kısa alıştırmalar
- 365 günlük ilerleme, seri takibi ve takvim

Site, Cloudflare/Sites üzerinde buildless HTML olarak yayınlanır. Kaynakların kalıcı yedeği Sites kaynak deposundaki Git geçmişinde tutulur.
